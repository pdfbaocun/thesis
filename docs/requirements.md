# まとめサイト「今日の論文」要件定義

## 1. 目的
LINEに届いた論文要約を、あとから一覧で振り返れるようにする。

## 2. 利用者・公開範囲
- 一般公開(URLを知っていれば誰でも閲覧可)
- ログインなし、閲覧専用
- 公開先: GitHub Pages(`https://pdfbaocun.github.io/thesis/`)

## 3. 機能
| # | 機能 | 内容 |
|---|---|---|
| F1 | 論文一覧 | 新しい順に表示。各カードに日付・分野・タイトル和訳・ジャーナル名 |
| F2 | 詳細ページ | 要約全文(背景・方法・結果・結論・ひとこと)、原題、著者、PubMed/DOIリンク |
| F3 | 分野の絞り込み | 「すべて/角膜/硝子体」のタブで切り替え |
| F4 | LINEとの連携 | LINEのメッセージ末尾に、その論文の詳細ページへのリンクを付ける |

## 4. 非機能要件
- **スマホ優先:** 片手で読める文字サイズ・レイアウト。PCでも崩れない
- **自動更新:** 毎朝のLINE送信と同時にサイトも更新する。手作業は不要
- **費用:** 追加なし(GitHub Pagesは無料)
- **表示速度:** 静的サイトとし、サーバーを持たない
- **堅牢性:** サイトの更新に失敗しても、LINEへの配信は止めない

## 5. データ
- 毎日の要約を論文ごとに保存する(`data/papers.json`)
- 2026-09-27に送信済みの2本は、Geminiで要約を作り直して掲載する
  - 作り直すため、LINEで届いた文面とは表現が少し異なる

## 6. 対象外(今回はやらない)
- キーワード検索、既読・お気に入り・メモ、ログイン
  - 後から追加できる作りにしておく

## 7. 注意点
- 抄録の原文(英語)は掲載しない。Geminiによる日本語要約とPubMed/DOIへのリンクのみ掲載する(抄録の著作権は出版社側にあるため)
- LINEの文面はリンクの追加以外は変えない
